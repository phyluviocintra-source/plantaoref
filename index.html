Sincronização com GitHub

Preencha uma vez só. Esses dados ficam salvos apenas neste navegador (localStorage) — nunca são enviados a nenhum lugar além da API do GitHub.

Como gerar o token 1. No GitHub, vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Em "Repository access", escolha "Only select repositories" e selecione apenas este repositório.
3. Em "Permissions" → "Repository permissions" → "Contents", selecione "Read and write".
4. Gere e copie o token (começa com github_pat_) — ele só aparece uma vez.
5. Cole aqui em cima. Guarde uma cópia em local seguro caso precise reconfigurar depois.
